Product

Composable by design

Composable agents, tools, and memory you can wire into production workflows, with tracing, guardrails, and evaluation built in from day one.

Agents

Role-scoped workers with their own tools and memory. Compose them into multi-step pipelines or let them collaborate.

Tool runtime

Typed tool calls with retries, timeouts, and sandboxing. Bring your own functions or use the built-in library.

Memory

Short-term context, long-term stores, and retrieval that stays inside your compliance boundary.

Guardrails

Policy checks on every input and output, with redaction and escalation paths you define.

Evaluations

Regression suites for prompts and agents, run automatically on every deploy.

Tracing

Full request timelines down to each token — debug production behavior in minutes, not days.
