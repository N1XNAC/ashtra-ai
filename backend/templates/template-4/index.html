FAQs

Questions, answered

Setup takes minutes and no credit card is required. Agents run inside your existing permissions, every action is written to an audit log, and any workflow can be paused with one click.

Do I need engineers?

No. If you can write the process in plain language, you can build an agent. Technical teams can drop into the API when they want to.

Where does my data live?

In your region, encrypted at rest. Agents act through your existing permissions — Vesper never gets a shadow copy.

What if an agent goes wrong?

Every workflow has a pause switch and full replay. You can revert any action from the audit log.

How is pricing metered?

By seats and active workflows, not by API call. Predictable billing even in busy months.
